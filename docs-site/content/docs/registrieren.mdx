---
title: Registrieren und Anmelden
description: Konto erstellen, E-Mail-Adresse bestätigen und wieder Zugriff auf dein Konto bekommen.
---

Die Nachhilfebörse nutzt ein Konto für alle Funktionen. Du registrierst dich einmal und meldest dich danach mit deiner E-Mail-Adresse und deinem Passwort an.

## Konto erstellen

1. Öffne die Anmeldeseite und wechsle zu **Registrieren**.
2. Trage deinen Vornamen und deinen Nachnamen ein.
3. Wähle deine Klasse oder Stufe. Zur Auswahl stehen die Klassen 5 bis 10 mit den Buchstaben a bis d sowie EF, Q1 und Q2.
4. Trage dein Geburtsdatum ein.
5. Trage deine E-Mail-Adresse ein.
6. Wähle ein Passwort mit mindestens 8 Zeichen.
7. Bestätige die Nutzungsbedingungen.
8. Wähle **Registrieren**.

Wenn du unter 16 Jahre alt bist, erscheint zusätzlich ein Hinweis zur Einwilligung der Erziehungsberechtigten. Diese Einwilligung ist für die Registrierung nötig.

Nach der Registrierung zeigt die Seite den Hinweis „Schritt 1 von 2. Danach bestätigst du deine E-Mail-Adresse.“ Du erhältst einen 6-stelligen Code per E-Mail.

### SV-Code bei der Registrierung

Das Formular hat ein optionales Feld für einen SV-Code. Dieses Feld gehört zur Verifizierung durch das SV-Team. Für die normale Registrierung kannst du es leer lassen.

## E-Mail-Adresse bestätigen

1. Öffne die E-Mail mit dem Bestätigungscode.
2. Gib deine E-Mail-Adresse und den 6-stelligen Code auf der Seite zur Bestätigung ein.
3. Bestätige den Code.

Der Code ist 30 Minuten gültig. Nach fünf falschen Eingaben wird der Code gesperrt.

Du kannst einen neuen Code anfordern. Zwischen zwei Anfragen liegt eine Wartezeit von 60 Sekunden. Pro Stunde und IP-Adresse versendet die Plattform höchstens fünf Bestätigungs-Mails.

Bis zur Bestätigung ist die Anmeldung gesperrt. Erst nach der Bestätigung wird dein Konto freigeschaltet.

### Wenn der Code nicht passt

- **Der Code ist abgelaufen.** Fordere einen neuen Code an.
- **Der Code stimmt nicht.** Prüfe die E-Mail-Adresse und den Code. Schau auch in den Spam-Ordner.
- **Zu viele Fehlversuche.** Fordere einen neuen Code an.

## Anmelden

1. Öffne die Anmeldeseite.
2. Trage deine E-Mail-Adresse und dein Passwort ein.
3. Wähle **Anmelden**.

Bei falschen Zugangsdaten zeigt die Seite „Ungültige Zugangsdaten. E-Mail oder Passwort falsch.“ Prüfe beide Angaben und versuche es erneut.

Wenn deine E-Mail-Adresse noch nicht bestätigt ist, verweigert die Plattform die Anmeldung. Bestätige zuerst deine E-Mail-Adresse.

## Passwort vergessen

1. Wähle auf der Anmeldeseite **Passwort vergessen**.
2. Trage deine E-Mail-Adresse ein.
3. Öffne den Link in der E-Mail und vergib ein neues Passwort.

Die Seite bestätigt den Versand immer mit demselben Hinweis. So lässt sich nicht erkennen, ob eine E-Mail-Adresse registriert ist. Der Link zum Zurücksetzen ist 2 Stunden gültig.

## Abmelden

Über **Abmelden** beendest du die Sitzung in deinem Browser. Eine Abmeldung auf einem anderen Gerät ist über die Plattform nicht möglich.

## Zwei Arten der Verifizierung

Die Nachhilfebörse unterscheidet zwei Schritte:

| Schritt | Was geprüft wird | Wo |
| --- | --- | --- |
| E-Mail-Bestätigung | Deine E-Mail-Adresse gehört zu dir. | Über den Code per E-Mail |
| SV-Verifizierung | Du gehörst zur Schule und darfst die Plattform nutzen. | Persönlich im SV-Raum |

Die E-Mail-Bestätigung allein reicht nicht aus. Für Anzeigen, Anfragen und den Chat brauchst du zusätzlich die SV-Verifizierung.
