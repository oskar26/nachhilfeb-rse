# Screenshots

Ablageort für die Bilder in der [`README.md`](../../README.md). Dateien hier ablegen. Die README verlinkt sie bereits.

## Benennung

| Dateiname | Motiv | Route / Ort |
|---|---|---|
| `01-welcome.png` | Landing / Startseite (Hero, CTA, drei Zielgruppen) | `/#/welcome` |
| `02-feed.png` | Feed mit Filtern (Fach, Klasse, Preis, verifiziert) | `/#/` nach Login |
| `03-anzeige-erstellen.png` | Stepper „Anzeige erstellen“ (biete/suche) | `/#/create-ad` |
| `04-anfrage-chat.png` | Anfragen-Übersicht oder Chat-Verlauf | `/#/requests` bzw. `/#/chat/…` |
| `05-profil.png` | Eigenes oder öffentliches Profil (Bio, Fächer, Bewertungen) | `/#/profile` bzw. `/#/profile/:id` |
| `06-eltern-dashboard.png` | Eltern-Dashboard (Kind, Fortschritt) | `/#/parent-dashboard` |
| `07-sv-panel.png` | SV-Panel (Verifikation, Codes oder Analytics) | `/#/sv-panel` |
| `08-coaching.png` | Coaching-Seite mit AG-Badge-Erläuterung | `/#/coaching` |
| `09-dark-mode-pwa.png` | Dark Mode und/oder PWA auf dem Homescreen | beliebige Seite, Dark Mode |

## Regeln

- **Format:** PNG, scharf, 1440×900 oder 1280×800 (Desktop). Für `09` darf es ein Handy-Screenshot sein.
- **Platzhalter ohne sensible Daten:** keine echten Namen, E-Mail-Adressen, Chats oder Profile von Mitschülern. Demodaten oder geschwärzt.
- **Einheitlich:** gleicher Browser-Frame, gleicher Zoom, möglichst Light **und** ein Dark-Mode-Schuss für `09`.
- **Größe:** möglichst unter ~500 KB pro Bild (PNG oder WebP).
