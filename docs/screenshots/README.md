## Regeln

- **Desktop-Format:** PNG, 1600 px Breite (Höhe entsprechend), scharf, gleicher Browser-Zoom.
- **Desktop-Rahmen:** dezenter Rahmen ist eingebrannt — 3 px Rand `#111111`, Ecken ~15 px abgerundet. Neue Desktop-Shots bitte mit der gleichen Behandlung ablegen (Resize 1600 px → Border → runde Ecken → `-strip`).
- **Geräte-Shots:** Bezel/Abschattung gehört ins Bild, kein zusätzlicher Rahmen.
- **Platzhalter ohne sensible Daten:** keine echten Namen, E-Mail-Adressen, Chats oder Profile von Mitschülern. Demodaten oder geschwärzt.
- **Größe:** möglichst unter ~500 KB pro Bild.
