## Der Kern in vier Sätzen

1. Die Nachhilfebörse ist eine **selbstgewählte Aufgabe der SV** zur Förderung fachlicher und
   sozialer Interessen — genau das, was § 74 Abs. 1 SchulG NRW und Nr. 2.2.1 des SV-Erlasses
   der SV ausdrücklich zuweisen.
2. Sie braucht **keine Genehmigung von Behörden**, keine Schulkonferenz-Mehrheit und keine
   Satzungsänderung — sie braucht die **Zustimmung der Schulleitung** (Nr. 6.2 SV-Erlass),
   damit sie als Schulveranstaltung gilt und die Schule Verantwortung übernehmen kann.
3. Der Aufwand für Lehrkräfte ist **eine Unterschrift und ein Raum-Zeitfenster**. Betrieb,
   Moderation und Verifizierung macht das SV-Team; die Verbindungslehrkräfte bleiben im Rahmen
   ihrer ohnehin bestehenden Aufgabe (Nr. 4.1–4.6 SV-Erlass) Ansprechperson.
4. **Die Nachhilfe selbst bleibt privat:** Die Börse vermittelt Kontakt, den Unterricht
   verabreden die Familien untereinander. Damit bleiben Aufsichtspflicht, Vergütung und
   Unfallversicherung dort, wo sie auch bei jeder anderen privaten Nachhilfe liegen.

## Zwei-Ebenen-Modell (das wichtigste Denkmodell im ganzen Gespräch)

| | **Ebene 1: Die Plattform** | **Ebene 2: Die Nachhilfe** |
|---|---|---|
| Was | Anmeldung, Verifizierung, Anzeigen, Chat, Moderation, Statistik | Der eigentliche Unterricht |
| Träger | SV (SV-Veranstaltung nach Zustimmung der SL) | Privat zwischen zwei Familien |
| Verantwortung | SV-Team + Schulleitung (schulisches Verfahren) | Die beteiligten Familien |
| Aufsicht nötig? | Nein — die SV organisiert, es gibt keine Aufsichtssituation | Nein — private Verabredung, keine Schulveranstaltung |
| Unfallversicherung | Schulveranstaltung → gesetzlich versichert | Privat → **nicht** gesetzlich versichert (DGUV) |
| Geld | fließt keins an SV/Schule | Honorar direkt zwischen den Familien |

Diese Trennung löst im Gespräch die meisten Nachfragen (Haftung, Aufsicht, Versicherung,
„Kommerzialisierung der Schule“) in einem Zug auf. Sie steht deshalb auch in der
Datenschutzerklärung, im Impressum und in den Nutzungsbedingungen so drin.
